# Articles

### Tutorials

Static, read-only versions of the interactive `learnr` tutorials bundled
with the package. Install the package and run `run_tute()` for the full
interactive experience.

- [Diversity and
  Regression](https://stocnet.github.io/infernet/articles/diversity-and-regression.md):

  This tutorial aims to teach you how to measure and test network
  diversity, moving from univariate to multivariate tests, including
  network linear models (multiple regression quadratic assignment
  procedures).
