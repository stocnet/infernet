# Articles

### Tutorials

Static, read-only versions of the interactive `learnr` tutorials bundled
with the package. To run them, install
[migraph](https://stocnet.github.io/migraph/) and run
`migraph::run_tute("diversity")`, `migraph::run_tute("diffusion")`,
`migraph::run_tute("opinion")`, or `migraph::run_tute("ERGMs")` for the
full interactive experience.

- [Diversity and
  Regression](https://stocnet.github.io/infernet/articles/diversity-and-regression.md):

  This tutorial aims to teach you how to measure and test network
  diversity, moving from univariate to multivariate tests, including
  network linear models (multiple regression quadratic assignment
  procedures).

- [Diffusion and
  Contagion](https://stocnet.github.io/infernet/articles/diffusion-and-contagion.md):

  In this tutorial you will learn how to simulate and investigate simple
  and complex diffusion or contagion on empirical or generated network
  structures, including independent cascades, compartmental models, and
  models of your own, and how to test whether a model fits an observed
  diffusion.

- [Opinion and
  Learning](https://stocnet.github.io/infernet/articles/opinion-and-learning.md):

  In this tutorial you will learn how to simulate how opinions change
  when people listen to those they are tied to, whether the opinions
  reach a consensus, how stubbornness, bounded confidence, and repulsion
  keep disagreement alive, which nodes have the most influence on where
  opinions end, and what that means for the wisdom of crowds and for
  misinformation.

- [Modelling with
  ERGMs](https://stocnet.github.io/infernet/articles/modelling-with-ergms.md):

  This tutorial aims to teach you how to model network structure using
  exponential random graph models (ERGMs).
