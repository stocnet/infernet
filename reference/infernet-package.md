# infernet: Inferential Models for Many Different Types of Networks

Tools for testing and modelling network data. Provides conditional
uniform graph and quadratic assignment procedure tests of network
statistics, and multiple regression quadratic assignment procedure
(MRQAP) models (Krackhardt 1988
[doi:10.1016/0378-8733(88)90004-4](https://doi.org/10.1016/0378-8733%2888%2990004-4)
; Dekker, Krackhardt, and Snijders 2007
[doi:10.1007/s11336-007-9016-1](https://doi.org/10.1007/s11336-007-9016-1)
) for a range of families, with random and fixed effects, missing data,
and cognitive social structures. Built on the 'manynet' package, all
functions operate with matrices, edge lists, and 'igraph', 'network',
and 'tidygraph' objects, and on one-mode and two-mode (bipartite)
networks.
